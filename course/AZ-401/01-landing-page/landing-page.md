## ❓ Frequently Asked Questions

**Q: How is Exam AZ-401 different from Exam AZ-400?**
While AZ-400 focused ~50–55% on traditional CI/CD pipelines, **AZ-401** rebalances pipelines to **35–40%**, raises **Processes & Communications (`15–20%`)**, **Security (`15–20%`)**, and **Instrumentation (`15–20%`)**, and tests **Agentic DevOps** across every domain: GitHub Copilot coding/cloud agents, `.instructions.md`/`SKILL.md`/`AGENTS.md`, `copilot-setup-steps.yml`, Azure DevOps & GitHub MCP servers, `git worktree`, `gh ado2gh`, GitHub Agentic Workflows (`gh-aw`), Azure Copilot Observability Agent, Azure SRE Agent, and Copilot session-log auditing.

**Q: What prerequisite certification is required to earn Agentic DevOps Engineer Expert?**
Per Microsoft's October 15, 2026 announcement, earning **`Microsoft Certified: Agentic DevOps Engineer Expert`** requires passing **Exam AZ-401** **plus** holding an active **`Microsoft Certified: GitHub Copilot` (`GH-300`)** **or** **`Microsoft Certified: Azure Administrator Associate` (`AZ-104`)** certification.

**Q: How does beta scoring work if I sit AZ-401 during the public beta window?**
Exam AZ-401's public beta runs through **November 9, 2026**, with General Availability targeted for **December 2026**. Beta candidates do not receive an instant score on test day; Microsoft statistically evaluates beta item performance and posts your `700 / 1000` scaled score roughly 10 days after the exam goes live globally.

**Q: Are these real or recalled AZ-401 beta questions?**
No. Every single question, case study, and explanation is 100% original educational material authored from Microsoft Learn's October 13, 2026 study guide and primary Microsoft/GitHub documentation.

**Q: Can I use GitHub Docs during the proctored AZ-401 exam?**
No — Pearson VUE provides split-screen access to **`learn.microsoft.com`** during non-lab sections, while `docs.github.com` and external search engines are blocked. That makes mastering GitHub Copilot agent primitives, `copilot-setup-steps.yml`, `gh ado2gh`, and `gh-aw` syntax before exam day especially high-leverage.

**Q: Which CSV should instructors upload to Udemy?**
Upload `03-practice-sets/set-{1..6}/case-embedded-set-{1..6}.csv` (`max 705` chars per stem) so Udemy's question shuffling keeps every 3-question case study attached to its scenario brief.
