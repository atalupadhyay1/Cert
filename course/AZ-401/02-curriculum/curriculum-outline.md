# Exam AZ-401 Curriculum Outline & Mock-Exam Architecture

Udemy Practice-Test-Only courses organize directly into **6 full-length timed practice tests** (`100` questions and `100` minutes each = `600` original items). Every test mirrors the **October 13, 2026** Exam AZ-401 blueprint (`17 / 13 / 38 / 16 / 16` across Domains 1–5) while immersing learners in four distinct enterprise Agentic DevOps case studies.

> **Prerequisite & Beta Context:** Earning **`Microsoft Certified: Agentic DevOps Engineer Expert`** requires passing **Exam AZ-401** plus holding an active **`GH-300` (`GitHub Copilot`)** or **`AZ-104` (`Azure Administrator Associate`)** certification. Exam AZ-401 is in **public beta** through **November 9, 2026** (GA targeted **December 2026**), succeeding **Exam AZ-400** (retiring **February 1, 2027**). Microsoft's passing threshold is a **700 / 1000** scaled score.

## Recommended Candidate Study Loop

1. **Take Timed Passes (`1.0 min / question`):** Sit one 100-question set at a time without pausing; practice quick recognition of YAML/JSON/Bicep/KQL `____` completions and 4-step `→` sequences.
2. **Audit Every Distractor Rationale:** Every wrong option explains *why* that tempting configuration fails (for example, why `copilot-setup-steps.yml` on a feature branch is ignored, or why `write-all` breaks `gh-aw` sandboxing).
3. **Practice Microsoft Learn Navigation:** During the real AZ-401 exam you have split-screen access to Microsoft Learn (not GitHub or arbitrary search engines)—use the linked Microsoft Learn URLs in `Overall Explanation` to build muscle memory for official doc structure.
4. **Target `>= 85%` Across Domains:** While `85%` in practice does not equal Microsoft's `700 / 1000` scaled score, consistent high domain accuracy across all 5 functional groups indicates readiness across both agentic and core DevOps objectives.
