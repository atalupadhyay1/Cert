### 3. Course Description

```text
Can you get real work done with Microsoft 365 Copilot — draft the document, summarize the meeting, analyse the workbook, choose the right agent, and know when to check the answer yourself?

Prepare for Microsoft AB-730 (AI Business Professional) with 600 original questions across six full-length mock exams of 100 items each. Every exam is blueprint-weighted, so each one is a coherent rehearsal of the whole blueprint rather than a random topic dump.

This is not a developer exam. It expects a working business user's judgement: how Copilot uses context from Work IQ, the web, and the app you are in; how tenant protection and permission trimming decide what an answer can see; how to write, refine, save, schedule, and share a prompt; how to draft and analyse content across Word, Excel, PowerPoint, and Teams; how to prepare for a meeting, use Facilitator, catch up in real time, and turn a recap into actions; and how to choose between Copilot Chat, a prebuilt agent, a scoped custom agent, and Microsoft Copilot Cowork for a multi-step task. It also expects you to recognise the failure modes you personally own: a confident false statement, an instruction hidden in an uploaded document, over-reliance, and sensitive content in the wrong place.

WHAT YOU GET
• Six 100-question mock exams — 600 original items in total
• 84 multiple-choice and 16 multi-select items per exam, plus 8 sequencing items rendered as candidate sequences
• 24 case studies across the package — four per exam, one from each domain, three questions each
• An explanation for EVERY option, not only the correct one
• A whole-question rationale that names the constraint that decides the answer
• A local study-map skill and a Microsoft Learn reference on every item
• Offline Markdown review copies for every exam, plus a case-study brief bundle and a one-block sample upload
• A reproducible ZIP, a CSV format specification, and a pre-flight checker

HOW THE EXAMS ARE BUILT
Each exam carries the same 28 / 24 / 24 / 24 allocation across the four official domains, so every exam sits inside all four published ranges. Multi-select stems always state the count ("Select two"). Sequencing items offer four candidate orders with exactly one correct sequence and export as multiple-choice, because that is what a bulk uploader accepts.

WHAT THIS IS NOT
This is an expanded practice bank, not a replica of the live assessment. Microsoft publishes no item count for AB-730. Hot-area image selection, drag-and-drop interfaces, labs, live tenant components, and adaptive problem-solution sets cannot be reproduced in a CSV and are disclosed as a boundary rather than simulated.

Concepts and option definitions recur across exams for reinforcement. Six hundred distinct question stems do not mean six hundred independent concepts or six independent readiness estimates. No score, calibrated difficulty, or certification result is guaranteed.
```

## 🧪 How the case studies work

Each exam has four case studies of three questions, one drawn from each domain. The scenario is written once and the three items are scored individually.

The player has no case-study container, so the scenario is delivered in one of three ways:

1. **Lecture resource first** — paste the four scenarios from `04-resources/case-studies.md` into a lecture before the practice test, then upload the short-stem CSV. This is the recommended route.
2. **Embedded stems** — upload `case-embedded-set-N.csv`, where each case stem repeats its scenario. Use this when the platform shuffles questions.
3. **By hand** — type the scenario and question into the builder when an item needs a table or an image.

Do not upload `practice-set-N.csv` and `case-embedded-set-N.csv` into the same practice test: they contain the same 100 items and the same keys.

## ❓ Frequently Asked Questions

**Is this course affiliated with Microsoft?**
No. It is independent educational content, not endorsed by or affiliated with Microsoft. No item is an actual, recalled, or copied exam question.

**Does it guarantee a pass?**
No. It provides 600 explained practice items and a study structure. A practice percentage is not a scaled exam score, and Microsoft publishes no raw percentage equivalent to 700/1000.

**Why 100 items when the real assessment is shorter?**
Microsoft does not publish an item count for AB-730. A 100-item exam covers the blueprint twice over and lets you drill a domain without repeating items. It is an expanded bank, not a claim about the live length.

**Do I need a Microsoft 365 licence or a lab tenant?**
No. Every question is answerable from documented product behaviour and business judgement. A tenant helps for hands-on practice, but no lab is required.

**Why are sequencing questions labelled multiple-choice?**
The bulk importer accepts only `multiple-choice` and `multi-select`. Each sequencing item already offers four complete candidate orders with one correct sequence, so it exports unchanged as a multiple-choice item.

**Why does every option have an explanation?**
Because the useful learning is in why the near-miss fails. Each option carries a rationale, and the whole-question explanation names the constraint that decides the item.

**The guide changed in October 2026 — is this current?**
Yes, this package follows the study guide dated 20 October 2026, including the agents domain and Copilot Cowork. Microsoft can change the guide again; check the live page before booking.

**Can I upload this to Udemy?**
The CSVs follow the 17-column bulk-upload format and pass the repository's pre-flight checker. That is a format check, not a guarantee that a platform will accept the file or that the course is published. Preview the import before publishing.

**Are the case studies reproducible in a CSV?**
The scenario travels either as a lecture resource, as embedded text in each case stem, or by hand. The case block itself is three ordinary questions with a shared preamble, because the player has no case-study container.
