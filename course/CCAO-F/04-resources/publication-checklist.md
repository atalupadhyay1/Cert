# Publication checklist

## Before upload

- [ ] Confirm the current official exam guide, format, fee, validity, and version on the certification portal.
- [ ] Confirm whether the announced December 7, 2026 update applies to the intended exam date.
- [ ] Run the builder, validator, packaging script, and full test suite; keep the passing report.
- [ ] Confirm six CSVs each have 100 rows, four options, one correct answer, and complete explanations.
- [ ] Spot-check at least 20 items for factual accuracy, ambiguity, and answer uniqueness.
- [ ] Have a qualified reviewer check governance, privacy, legal, and accessibility-sensitive wording.
- [ ] Confirm no official sample, recalled item, competitor question, or proprietary text was copied.
- [ ] Confirm titles, subtitles, outcomes, requirements, and audience statements match the delivered content.
- [ ] Check all local links and the ZIP contents.
- [ ] Reconfirm every product-behavior claim against current documentation.

## Platform setup

- [ ] Create the course shell and paste the landing-page metadata blocks into the matching fields.
- [ ] Verify title and subtitle against current character limits.
- [ ] Add the welcome and congratulations messages.
- [ ] Import each CSV into the correct practice test and preview every question type.
- [ ] Confirm the platform did not alter option order, correct indices, or explanation text.
- [ ] Set the optional practice duration and target as clearly custom, if used.
- [ ] Add the version-boundary statement to the course description and a visible lecture or resource.

## Integrity and claims

- [ ] State that items are original educational practice, not official or recalled exam content.
- [ ] State that the package is independent and not endorsed by Anthropic or Udemy.
- [ ] Avoid implying that practice percentages equal the scaled exam score.
- [ ] Avoid implying these single-answer tests replicate the multiple-response exam.
- [ ] Avoid implying automatic readiness, guaranteed pass, or official approval.
- [ ] Keep pricing, model, plan, and feature statements out of deterministic claims; use dated verification.

## After publication

- [ ] Monitor learner reports of ambiguous or outdated items.
- [ ] Record the published version and guide baseline.
- [ ] Schedule a refresh for the November 17, 2026 guide and any later changes.
- [ ] Revalidate the package after any product, policy, or blueprint change.
