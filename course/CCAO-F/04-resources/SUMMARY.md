# CCAO-F package summary

This course is **Claude Certified Associate – Foundations (CCAO-F)**.

- Six tests × 100 original single-answer questions = 600.
- Four options per item, one best answer, per-option explanations, case rationale.
- Seven official domains, 32 local study-map skills, all mapped in exports.
- Test 6 approximates official weights 14/21/12/16/12/15/10.
- Actual exam: 60 items, 120 minutes, multiple-choice and multiple-response, 720 on a 100–1,000 scale, $99, 12 months, no mandatory prerequisites.
- Practice format is intentionally different and is disclosed throughout.
- Offline ZIP: `Claude-CCAO-F-Udemy-6x100.zip`.
