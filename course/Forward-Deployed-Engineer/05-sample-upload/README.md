# Sample Upload (`18` Questions) — Forward Deployed Engineer

`sample-upload.csv` contains **18 representative questions** (`3` per domain: `2` `multiple-choice` + `1` `multi-select` across all `6` Forward Deployed Engineer domains) exported from Set 1 with identical UTF-8-BOM 17-column Udemy formatting.

## How to Use
1. Create a draft Practice Test in Udemy and upload `sample-upload.csv` first to confirm instant zero-error ingestion of `multiple-choice`, `multi-select`, inline code backticks, `→` sequences, `____` completions, and `Domain` tags.
2. Delete the draft test (or replace its contents) and upload `03-practice-sets/set-{1..6}/practice-set-{1..6}.csv` (`100` questions each, `120-minute` recommended timer, `65%–75%` practice benchmark).
