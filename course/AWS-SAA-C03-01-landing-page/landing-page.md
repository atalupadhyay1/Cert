**Q: Is SAA-C03 the current exam?**
A: Yes. SAA-C03 has been the active exam since August 30, 2022, and was refreshed in 2026. As of Q3 2026, SAA-C04 has not been announced.

**Q: How many questions are on the real exam?**
A: 65 questions total (50 scored + 15 unscored pretest). The unscored questions are not identified, so treat every question as if it counts.

**Q: How long is the real exam?**
A: 130 minutes. We recommend completing Set 6 (full-length simulation) inside 130 minutes to practice real exam pacing.

**Q: What's the passing score?**
A: 720 out of 1000 (scaled — not a flat 72%).

**Q: Does the certification expire?**
A: Yes. SAA-C03 is valid for 3 years. Recertify by passing the current SAA-C03 again or by earning the AWS Solutions Architect - Professional (SAP-C02).

**Q: How is this different from the AWS Skill Builder practice exams?**
A: The AWS Skill Builder exams are short (20 questions). This course gives you 1200 questions across 6 sets with detailed per-option explanations and case studies — closer to a real classroom prep experience.

**Q: Are these questions copied from AWS?**
A: No. Every question is original, written from the official AWS SAA-C03 exam guide and AWS documentation, and every explanation cites an AWS documentation URL.
