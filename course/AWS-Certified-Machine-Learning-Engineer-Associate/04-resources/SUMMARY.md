# MLA-C02 package summary

This course covers the **AWS Certified Machine Learning Engineer – Associate (MLA-C02)** certification.

- Six mock exams × 65 original questions = **390**.
- Every exam is blueprint-weighted **18 / 16 / 16 / 15** against the published **28 / 24 / 24 / 24** percent. Those four weights total exactly 100; applied to 65 items they give 18.2 / 15.6 / 15.6 / 15.6, and because largest-remainder rounding would overshoot the paper by one item, the spare item comes out of Domain 4. Every count is within 0.6 items of its published weight, and the tests assert those exact counts so a weight change fails the build.
- Item mix per exam: **50 multiple-choice, 15 multiple-response**. Multiple-response items use five options and state the required count in the stem (4 / 4 / 4 / 3 across domains 1–4). **AWS publishes no split between the two item types**, so this mix is an authoring choice and is labelled as one in every set README, in the review copies, and on the landing page.
- **65 items is the published paper length.** The exam guide defines 65 questions in 130 minutes, of which 50 are scored and 15 are unscored and unidentified. At 65 items in 130 minutes the bank runs at about **120 seconds per item**, the same pace as a scored sitting. The one honest difference: a practice percentage here measures all 65 items, while 15 live items do not count.
- **Beta status is disclosed, not hidden.** MLA-C02 replaced MLA-C01 in English on 29 September 2026 and is currently delivered as **85 questions in 170 minutes for 75 USD in English only**, with the additional items unscored and no pass/fail result. These sets follow the published 65-question form.
- **No case studies.** The published format is multiple choice and multiple response with no case-study component, so the bank has no `Case study —` stems, no `cases.py`, and no case-study documents. `build.py` refuses to build if a case phrase reaches a stem or rationale, `validate.py` rejects case wording in an export, and `package.py` rejects a reinstated case-study file.
- **Implementation decisions, not platform architecture.** The guide places end-to-end solution design, ML strategy and best practice, integration with a wide array of tools, and depth in two or more ML domains out of scope. Items ask which store, model, tuning objective, endpoint type, scaling metric, monitor or control fits a stated requirement. No item is a console recipe and none needs an AWS account; the test suite rejects console-instruction phrasing (`click`, `navigate to`, `in the console, select`).
- **No sequencing or drag-and-drop items.** Those formats are not part of the published format.
- Four official domains and **45 local study-map skills**, all exercised, mapped in every export.
- Per-option explanations plus a rationale, exam-guide reference, local skill, and primary reference on every item.
- Exam baseline: **130 minutes**, **150 USD**, **65 questions (50 scored + 15 unscored)**, multiple choice and multiple response, Pearson VUE test centre or online proctoring, a **scaled score of 100–1000 with a minimum passing score of 720** under compensatory scoring with no per-domain pass mark, and **three-year validity** — all AWS-published on the certification page and in the guide. AWS recommends at least one year of experience with SageMaker AI, Amazon Bedrock and other ML engineering services, plus a year in a related role.
- **720 is stated as published and decoupled from practice percentages.** It is a scaled score, not a percentage of 65, so no target percentage appears anywhere and no practice result is converted into a scaled score.
- Product vocabulary follows the MLA-C02 exam guide: Amazon S3 with Parquet, ORC, JSON and CSV and the Standard, Intelligent-Tiering, Standard-IA and Glacier classes; Amazon EBS; Amazon EFS; Amazon FSx for Lustre; Amazon RDS with pgvector; Amazon DynamoDB; Amazon OpenSearch Service; AWS Glue with the Data Catalog and Data Quality; AWS Glue DataBrew; SageMaker Data Wrangler; Amazon EMR; AWS Database Migration Service; Amazon Kinesis Data Streams; Amazon Data Firehose; Amazon MSK; AWS Lambda; SageMaker Feature Store; SageMaker Ground Truth with automated labelling; SageMaker Clarify; SageMaker AI training jobs with built-in algorithms, script mode, automatic model tuning, managed Spot training, warm pools, distributed training and training plans; SageMaker Pipelines; SageMaker Model Registry; SageMaker Inference Recommender; SageMaker Neo; SageMaker HyperPod; real-time, serverless, asynchronous and batch inference; multi-model and multi-container endpoints; Amazon Bedrock with foundation models, embeddings, provisioned throughput, custom model import, Prompt Management, knowledge bases, Guardrails, model evaluation and AgentCore Observability; Amazon Textract, Comprehend, Transcribe and Rekognition; Amazon CloudWatch with metrics, alarms, dashboards, Logs Insights and generative AI observability; AWS X-Ray; AWS CloudTrail; AWS Config; Amazon Inspector; Amazon CodeGuru; AWS CodeCommit, CodeBuild, CodeDeploy, CodePipeline and CodeConnections; Amazon ECR; Amazon ECS; Amazon EKS; AWS Batch; AWS Step Functions; Amazon EventBridge; AWS Secrets Manager; AWS KMS; IAM roles, policies and AWS Organizations service control policies; VPC subnets, security groups, interface endpoints and NAT gateways; and Cost Explorer, AWS Budgets and Savings Plans.
- Not reproduced: lab tasks, in-console exercises, and any interactive item format, because they cannot exist in a CSV and are not part of the published format.
- Offline ZIP: `AWS-Certified-Machine-Learning-Engineer-Associate-6x65.zip`.

Automated checks cover structure, exact blueprint allocation, per-skill plan, multiple-response spread, item-type mix, source parity, explanation pairing, CSV bytes, cross-exam duplicate wording, a token-overlap near-duplicate gate at 0.72 across all 390 stems, the absence of case wording, the absence of console-recipe phrasing, and archive reproducibility. They do not establish independent technical accuracy, psychometric quality, platform import success, or a passing result.

Practice percentages are not scaled scores, and passing the real exam requires a scaled 720 that this course cannot predict.
