# PL-300 package summary

This course covers **Microsoft Certified: Power BI Data Analyst Associate (PL-300)**.

- Six mock exams × 100 original questions = **600**.
- Every exam is blueprint-weighted **28 / 28 / 28 / 16** = 28 / 28 / 28 / 16 percent, inside all four published ranges (25–30 / 25–30 / 25–30 / 15–20).
- Item mix per exam: **76 multiple-choice, 16 multi-select**, plus **4 case studies of 3 questions**. Eight of the multiple-choice items are sequencing items with four candidate sequences.
- Multi-select stems state the required count; sequencing items offer four candidate sequences and export as `multiple-choice`, because the importer accepts only `multiple-choice` and `multi-select`.
- Four official domains, 30 local study-map skills, all mapped in exports.
- Per-option explanations plus a case rationale, study-guide anchor, local skill, and primary reference on every item.
- Exam baseline: **typically 40–60 questions**, 100 minutes, 700/1000 scaled pass, $165 USD, proctored, valid 1 year with free renewal, study guide measured as of **April 20, 2026**, exam sandbox published by Microsoft.
- Each exam is 100 items, deliberately larger than the typical 40–60, so the blueprint can be drilled twice; it is an expanded bank, not a length replica.
- Not reproduced: hot-area items, drag-and-drop UI, labs and interactive components, adaptive problem-solution sets, and the exact live item count.
- Offline ZIP: `PL-300-Power-BI-Data-Analyst-6x100.zip`.

Automated checks cover structure, blueprint allocation, item-type mix, source parity, explanation pairing, CSV bytes, cross-exam duplicate wording, and archive reproducibility. They do not establish independent technical accuracy, psychometric quality, platform import success, or a passing result.

A practice percentage is not a scaled exam score. Microsoft does not publish a raw percentage equivalent to 700/1000.
