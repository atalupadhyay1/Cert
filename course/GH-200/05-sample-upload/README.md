# Quick-Smoke Udemy Sample Upload (`sample-upload.csv`) — Exam GH-200

Use this file to smoke-test Udemy's Bulk Question Upload importer in ~5 seconds before uploading all six 100-question CSV files (`03-practice-sets/set-{1..6}/practice-set-{1..6}.csv`).
