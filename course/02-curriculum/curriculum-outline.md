# AB-900 Practice Test Course — Curriculum Outline & Strategy

> **Complete curriculum blueprint for all 6 practice test sets.** Each set is 100 questions, mapped to the official AB-900 exam objective domains (skills measured as of October 14, 2026).

---

## 📊 OFFICIAL AB-900 EXAM DOMAIN BREAKDOWN

| Domain | Exam Weight | Practice Coverage |
|---|---|---|
| **Identify the core features and objects of Microsoft 365 services** | 30–35% | Sets 1, 2, 5, 6 |
| **Understand data protection and governance tasks for Microsoft 365 and Copilot** | 35–40% | Sets 1, 3, 5, 6 (heaviest) |
| **Perform basic administrative tasks for Copilot and agents** | 25–30% | Sets 1, 4, 5, 6 |

> ℹ️ **Question Pool Logic:** Because Domain 2 (Data Protection & Governance) is the largest, every set has **at least 30 questions** from Purview/Copilot data security. Domain 1 and Domain 3 alternate as the secondary emphasis to keep all three domains well-represented across the suite.
