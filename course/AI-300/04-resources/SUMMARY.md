# AI-300 package summary

This course covers **Microsoft Certified: Machine Learning Operations Engineer Associate (AI-300)**.

- Six mock exams × 100 original questions = **600**.
- Every exam is blueprint-weighted **18 / 29 / 23 / 15 / 15** = 18 / 29 / 23 / 15 / 15 percent, inside all five published ranges (15–20 / 25–30 / 20–25 / 10–15 / 10–15).
- Item mix per exam: **76 multiple-choice, 16 multi-select**, plus **4 case studies of 3 questions**. Eight of the multiple-choice items are sequencing items with four candidate sequences.
- Multi-select stems state the required count; sequencing items offer four candidate sequences and export as `multiple-choice`, because the importer accepts only `multiple-choice` and `multi-select`.
- Five official domains, 36 local study-map skills and 24 case-study scenarios, all mapped in exports.
- Per-option explanations plus a case rationale, study-guide anchor, local skill, and primary reference on every item.
- Exam baseline: study guide **skills measured as of October 15, 2026**, passing score **700/1000 scaled**, proctored delivery. Microsoft does not publish an AI-300 item count or a duration on the study guide; confirm fee, duration, and renewal terms on the certification page.
- Each exam is 100 items, so the blueprint can be drilled twice; it is an expanded bank, not a length replica, and no live item count is implied.
- Configuration is deliberately in scope: items show Bicep, `az ml`, GitHub Actions, MLflow, prompt-flow structure, traffic splits, and evaluation settings, and test the judgement behind the change rather than flag recall.
- Not reproduced: drag-and-drop UI, hot-area items, live labs, adaptive problem-solution sets, and the live item count.
- Offline ZIP: `AI-300-MLOps-Engineer-Associate-6x100.zip`.

Automated checks cover structure, blueprint allocation, item-type mix, source parity, explanation pairing, CSV bytes, cross-exam duplicate wording, case-scenario coverage, and archive reproducibility. They do not establish independent technical accuracy, psychometric quality, platform import success, or a passing result.

A practice percentage is not a scaled exam score. Microsoft does not publish a raw percentage equivalent to 700/1000.
