HOW THE ITEM MIX MATCHES THE REAL EXAM
The live role-based exam is not a glossary quiz. Microsoft publishes a scaled pass score of 700/1000 and a five-domain blueprint, and candidates routinely see case studies, multi-select items, and scenario questions about a concrete workspace, pipeline, or flow.

These mock exams reproduce what a CSV player can score honestly:
• Single-choice items with one best answer.
• Multi-select items that state the required count ("Select two") and accept a comma-separated key.
• Ordering items rendered as four candidate sequences, so sequencing judgment is tested without a drag-and-drop UI.
• Case studies: a shared scenario followed by three scored questions, exactly as a case-study block behaves in the exam.

What is deliberately not reproduced, and is stated in every export: drag-and-drop and hot-area UI, live labs and interactive components, adaptive problem-solution (yes/no) sets, and the live item count.

HOW THE FILES ARE EXPORTED
Udemy's bulk question importer accepts only two `Question Type` values: `multiple-choice` and `multi-select`. Every file here therefore exports 84 multiple-choice and 16 multi-select items per exam. The eight sequencing items are authored as four candidate orderings with one correct answer, so they upload as ordinary multiple-choice items — no drag-and-drop UI is required and scoring stays exact.

Microsoft does not publish an AI-300 item count, so this package does not pretend to match one. Each exam contains four case studies of three questions. The three items in each block share one organization and are scored individually, which mirrors how a case-study block feels in the exam: read once, answer several linked questions, and keep the constraints straight.

**Where the scenario text is.** Every scenario is authored once in `04-resources/cases.py` and published three ways:

- **Study copy** — `practice-set-N.md` prints the full scenario under each `## Case study — <Name>` heading, before its three questions.
- **Brief bundle** — `04-resources/case-studies.md` collects all 24 scenarios with their questions and answer letters; upload it as a PDF or lecture resource.
- **Self-contained CSV** — `case-embedded-set-N.csv` repeats the scenario inside every case-item stem, for platforms that shuffle item order.

The default `practice-set-N.csv` keeps the stems short, because a Udemy question field holds one block of text and repeating a 90-word scenario three times per case reads badly in the player. Build both variants with `python build.py --embed-case`.

## ❓ Frequently Asked Questions

**Q: How many questions are included?**

A: **600 across six exams of 100**, with 76 multiple-choice, 16 multi-select, and 4 case studies of 3 questions per exam. Eight of the multiple-choice items per exam ask you to choose the correct candidate sequence.

**Q: Is every exam blueprint-weighted?**

A: Yes. All six use **18 / 29 / 23 / 15 / 15**, which is 18 / 29 / 23 / 15 / 15 percent — inside every published range (15–20 / 25–30 / 20–25 / 10–15 / 10–15).

**Q: Why 100 questions when Microsoft publishes no item count?**

A: So every sub-objective gets real coverage and each blueprint can be drilled twice without repeats. The package states plainly that it does not know the live count rather than implying a match.

**Q: Do these reproduce the actual exam?**

A: No. They reproduce the scoreable formats — single-choice, multi-select, ordering as candidate sequences, and case studies — and state which formats they exclude.

**Q: Why does this course include code and configuration when most practice tests do not?**

A: Because AI-300 tests it. An MLOps engineer is judged on reading a module, a job definition, or a traffic split and deciding what to change. Every such item still tests judgement, not flag recall, and no item requires you to write code from scratch.

**Q: Do I need an Azure subscription?**

A: No. Every question is answerable from the configuration shown and the reasoning. A subscription helps you reproduce a configuration, which is recommended but not required.

**Q: How are multi-select answers scored?**

A: The `Correct Answers` column lists every correct option index as a comma-separated value, for example `2,4`. The stem states the count ("Select two"), so a learner knows how many to choose. There is no partial credit.

**Q: How are sequencing questions scored and exported?**
