## ❓ FAQ

**Q: Why 100 questions when the exam has 50–60?**
Because 100 items let each of the 59 study areas carry enough questions to be diagnosed, and 600 items let the blueprint be drilled twice without repeating a question. The consequence is stated rather than hidden: 100 items in two hours is about 72 seconds per item, while the live 50–60 item paper allows 120–144 seconds. This bank runs **slower** per item than the real exam, so it is a comfortable timed rehearsal, not a speed simulation. Every exam is labelled an expanded bank on its README.

**Q: Why are there no case studies?**
Because the Professional Cloud DevOps Engineer exam does not have a case-study component. Google's certification page and the exam guide describe 50–60 multiple-choice and multiple-select questions and nothing else. A case-study block here would imitate a different certification format, so it is omitted — and the omission is stated rather than quietly filled.

**Q: Why is configuration content included here, when some exams have none?**
Because this exam tests it. The guide asks about CI/CD architecture, deployment strategy, alerting policy, log routing, cost controls and IAM boundaries, so items legitimately describe those choices. Every item still tests judgement: what the setting makes possible, what it prevents, and what it costs to operate. No stem asks you to click through a console or requires a live project, and the test suite rejects console-recipe phrasing.

**Q: What score do I need?**
Google does not publish a passing score for PCDOE, so this course does not state one. Score each item correct or incorrect, group misses by local skill ID, and treat improvement per skill as the signal.

**Q: Is a Google Cloud account required?**
No. Every question is answerable from the stem and the options.

**Q: What about renewal?**
Google's certification page points candidates to its Renewal FAQs for the renewal process, eligibility period and validity timeline rather than stating them on the page; this course does not restate a duration or fee it cannot verify. The bank is built for the **standard** exam and is not calibrated to a renewal instrument.

**Q: How current is the content?**
The item bank follows the exam guide and the certification page as retrieved in October 2026, including current vocabulary — Infrastructure Manager, Config Connector, Cloud Foundation Toolkit, Cloud Deploy with Kustomize and Skaffold, GKE fleets and release channels, Cloud Workstations, Gemini Code Assist, Gemini Cloud Assist, Gemini CLI, Google Cloud Managed Service for Prometheus, Parameter Manager, Certificate Manager, Artifact Analysis, Binary Authorization, Dynamic Workload Scheduler and the reliability, cost, security and manageability recommenders. The publication checklist requires a product-name re-check before release.
