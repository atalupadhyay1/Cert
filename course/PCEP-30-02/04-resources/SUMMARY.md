# PCEP-30-02 package summary

This course covers the **PCEP™ – Certified Entry-Level Python Programmer (Exam PCEP-30-02)** certification from the OpenEDG Python Institute.

- Six mock exams × 60 original questions = **360**, all snippet outputs and exceptions verified on **CPython 3.11**.
- Every exam is blueprint-weighted **11 / 17 / 15 / 17** against the published **18 / 29 / 25 / 28** percent across the four syllabus blocks. Exact shares at 60 items are 10.8 / 17.4 / 15.0 / 16.8; largest-remainder rounding assigns the two spare items to Blocks 1 and 4, keeping every count within 0.4 items of its weight.
- Item mix per exam: **45 multiple-choice** (including at least **15 single-blank `____` gap-fill / code-fill items**) and **15 five-option multiple-response items** (spread 3 / 4 / 4 / 4 across Blocks 1–4). Because the Python Institute publishes no fixed split across item formats, these counts are disclosed as authoring choices.
- **Expanded 2× bank at live per-item pace:** the live PCEP-30-02 exam delivers 30 items in 40 minutes (+5 minutes NDA/tutorial), or ~80 seconds per item. Each practice exam here delivers 60 items in 80 minutes so all 41 syllabus skills are exercised per sitting at the same ~80-second-per-item pace.
- **Interactive format boundary:** drag-and-drop, sort, and multi-slot code-insertion widgets on OpenEDG TestNow™ cannot exist in Udemy's 17-column CSV and are disclosed as excluded; single-slot gap-fill and code-fill items are approximated via `____` stems.
- **No case studies:** PCEP-30-02 has no case-study component, and `build.py`, `validate.py`, and `package.py` reject case wording or files.
- **Scope boundary:** stays strictly inside PCEP-30-02 (fundamentals, control flow, lists/tuples/dicts/strings, functions/generators/recursion/scope/exceptions); PCAP-31-03 topics (OOP classes, `pip`, file streams, closures) are excluded.
