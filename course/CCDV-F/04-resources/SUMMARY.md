# CCDV-F package summary

- Six focused/mixed learning tests; 600 original question stems and rationales.
- Four alternatives per question; one correct answer; detailed option definitions plus case rationale.
- Eight official domains, all 25 named guide skills; numeric mapping IDs are local.
- Guide v1.0 effective July 2026; reviewed October 21, 2026.
- Exam update announced December 7, 2026; revised guide due November 17. Future-scope coverage not asserted.
- Real exam: 53 items, 120 minutes, multiple-choice and multiple-response, 720 scaled passing score. Practice: 100 single-answer items, optional 200 minutes/80% custom study settings.
- Six instructor CSVs, six offline review copies, six set introductions, landing, curriculum, sources, manifest, report, tools, tests, and reproducible ZIP.
- Focused tests deliberately differ from exam weights; Test 6 uses 15/33/3/3/17/11/8/10.
- Concepts recur; no psychometric calibration, exhaustive factual certification, live SDK execution, Udemy import, or guaranteed pass.
