# PCNE package summary

This course covers the **Google Cloud Professional Cloud Network Engineer** certification.

- Six mock exams × 100 original questions = **600**.
- Every exam is blueprint-weighted **21 / 20 / 16 / 16 / 14 / 13**, which is exactly what Google publishes. The six published weights total **100%** already, so **no rounding adjustment was made** — every per-exam count is asserted equal to its published weight, with no tolerance band.
- Item mix per exam: **84 single-answer, 16 multi-select**. Multi-select items use five options and state the required count in the stem (4 / 3 / 3 / 3 / 2 / 1 across domains 1–6).
- **No case studies.** Google's published format is "50-60 multiple choice and multiple select questions" with no case-study component, so the bank has no `Case study —` stems, no `cases.py`, and no case-study documents. `build.py` refuses to build if a case phrase reaches a stem or rationale, `validate.py` rejects case wording in an export, and `package.py` rejects a reinstated case-study file.
- **Configuration judgement is in scope**, because this exam is largely about it: section 3 configures managed network services and section 6 configures security controls. Items describe service tiers, Shared VPC, IPAM, MTU, routing modes, MED and BFD, NAT port allocation, load-balancer backend settings, NGFW tiers and policy scope, and ask what a team should decide and why. No item is a console recipe and none needs a live project; the test suite rejects console-instruction phrasing (`click`, `navigate to`, `in the console, select`).
- **No sequencing or drag-and-drop items.** Those formats are not part of the published PCNE format.
- Six official domains and **54 local study-map skills**, all exercised, mapped in every export.
- Per-option explanations plus a rationale, exam-guide anchor, local skill, and primary reference on every item.
- Exam baseline: **two hours**, **$200 USD** plus tax, **50–60 multiple-choice and multiple-select questions**, English and Japanese, **no prerequisites** (3+ years of industry experience including 1+ year designing and managing solutions on Google Cloud recommended) — all Google-published on the certification page and in the guide. The **passing score is not published**, so no target percentage is stated anywhere. Google points candidates to its Renewal FAQs for the renewal process, eligibility period and validity timeline, so no duration or renewal fee is restated here; the bank targets the standard exam only.
- Each practice exam is 100 items, so the blueprint is drilled twice. It is an expanded bank: the live exam samples 50–60 questions.
- **The bank runs slower than the live exam per item.** 100 items in a two-hour sitting is about **72 seconds per item**; the live 50–60 item paper allows roughly **120–144 seconds**. Every set README, the landing page, and the curriculum say so, and the curriculum budgets 80 / 22 / 18 minutes.
- Product vocabulary follows the 24 April 2026 guide: Premium and Standard network service tiers, Shared VPC, VPC Network Peering, Network Connectivity Center (VPC, hybrid and producer spokes with CIDR filters), Private Service Connect, private services access, Serverless VPC Access, Cloud NAT and Private NAT, Cloud Router with global and regional dynamic routing, policy-based routes and an internal load balancer as next hop, Dedicated, Partner and Cross-Cloud Interconnect with VLAN attachments and MACsec, HA VPN and Classic VPN, BFD, Cloud DNS with forwarding, peering, inbound policies, geolocation, failover and DNSSEC, backend services, NEGs and URL maps, Cloud CDN, GKE networking with secondary ranges, Dataplane V2 and IP masquerade, Cloud Armor, Cloud NGFW Essentials/Standard/Enterprise with hierarchical, global and regional policies and secure tags, Secure Web Proxy, Packet Mirroring, and Network Intelligence Center including Connectivity Tests, Performance Dashboard, Firewall Insights, Network Analyzer, Flow Analyzer and Network Topology.
- Not reproduced: lab tasks, in-console exercises, and any interactive item format, because they cannot exist in a CSV and are not part of the published format.
- Offline ZIP: `Google-Professional-Cloud-Network-Engineer-6x100.zip`.

Automated checks cover structure, exact blueprint allocation, per-skill plan, multi-select spread, item-type mix, source parity, explanation pairing, CSV bytes, cross-exam duplicate wording, a token-overlap near-duplicate gate at 0.72 across all 600 stems, the absence of case wording, the absence of console-recipe phrasing, and archive reproducibility. They do not establish independent technical accuracy, psychometric quality, platform import success, or a passing result.

Google does not publish a passing score, so no practice percentage converts to a pass mark, and a practice percentage is not a scaled score.
