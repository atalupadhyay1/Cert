# AB-410 package summary

This course covers **Microsoft Certified: Intelligent Applications Builder Associate (AB-410)**.

- Six mock exams × 100 original questions = **600**.
- Every exam is blueprint-weighted **28 / 28 / 44** = 28 / 28 / 44 percent, inside all three published ranges (25–30 / 25–30 / 40–45).
- Item mix per exam: **76 multiple-choice, 16 multi-select**, plus **4 case studies of 3 questions**. Eight of the multiple-choice items are sequencing items with four candidate sequences.
- Multi-select stems state the required count; sequencing items offer four candidate sequences and export as `multiple-choice`, because the importer accepts only `multiple-choice` and `multi-select`.
- Three official domains, 33 local study-map skills and 24 case-study scenarios, all mapped in exports.
- Per-option explanations plus a case rationale, study-guide anchor, local skill, and primary reference on every item.
- Exam baseline: study guide **skills measured as of October 16, 2026**, passing score **700/1000 scaled**, published duration **120 minutes**, fee **$165 USD** on the certification page. Microsoft does not publish an AB-410 item count; confirm fee, duration, and renewal terms on the certification page.
- Each exam is 100 items, so the blueprint can be drilled twice; it is an expanded bank, not a length replica, and no live item count is implied.
- Configuration is deliberately in scope: items show Power Fx, form and view definitions, trigger and connector choices, approvals, business-rule scope, calculated and rollup settings, prompt settings, and solution and ALM decisions, and test the judgement behind the change rather than syntax recall.
- Not reproduced: drag-and-drop UI, hot-area items, live labs and interactive portal components, adaptive problem-solution sets, and the live item count.
- Offline ZIP: `AB-410-Intelligent-Applications-Builder-6x100.zip`.

Automated checks cover structure, blueprint allocation, item-type mix, source parity, explanation pairing, CSV bytes, cross-exam duplicate wording, case-scenario coverage, and archive reproducibility. They do not establish independent technical accuracy, psychometric quality, platform import success, or a passing result.

A practice percentage is not a scaled exam score. Microsoft does not publish a raw percentage equivalent to 700/1000.
