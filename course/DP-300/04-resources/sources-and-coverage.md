## Key Lifecycle & Platform Updates Reflected Across All 6 Sets

1. **Data Migration Assistant (`DMA`) retired July 2025:** Replaced by **Azure Migrate** (`Azure SQL` assessments) and the **Azure SQL Migration extension** for Azure Data Studio / VS Code (`Skill 1.10`).
2. **`database watcher` (preview) lifecycle:** Stops new watcher creation **November 9, 2026** and retires **April 30, 2027**, transitioning to **Database Hub in Microsoft Fabric** (`Skill 3.3`).
3. **SQL database in Microsoft Fabric & SQL Server enabled by Azure Arc:** Covered in every exam (`Skills 1.3, 1.5`).
4. **SQL Server 2022 / Compat 160 & Modern Security:** Bidirectional **Managed Instance link** online failover (`Skills 1.11, 5.2`), **online SQL MI database copy/move** (`Skill 1.12`), **VBS secure enclaves** (`Skill 2.9`), **SQL Ledger + Azure Confidential Ledger** (`Skill 2.14`), **Optimized Locking (`TID` + `LAQ`)** (`Skill 3.6`), and **PSP / DOP / Memory Grant Feedback** (`Skills 3.13, 3.14`).
