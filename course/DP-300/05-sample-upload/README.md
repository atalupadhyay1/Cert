# 🧪 Sample Upload Smoke Test (`case-study-sample.csv`)

`case-study-sample.csv` contains **12 self-contained case-study questions** (`4 cases × 3 questions`) extracted directly from **Set 1** (`KestrelCart Commerce`, `BrambleBox Stores`, `VelvetLoom Checkout`, and `HarborPick Fulfillment`) in Udemy's exact 17-column UTF-8-BOM CSV format.

## How to Use

1. Create a draft Practice Test in Udemy Instructor Studio.
2. Click **Bulk Upload Questions** and select `course/DP-300/05-sample-upload/case-study-sample.csv`.
3. Confirm all 12 items import cleanly with embedded `Case study — <Company>:` scenario context, `multiple-choice` and `multi-select` types, option-level rationales, `Overall Explanation` citations, and `Domain` tags.
4. Once verified, delete the draft smoke test (or replace its questions) and upload `03-practice-sets/set-{1..6}/case-embedded-set-{1..6}.csv` across your 6 production practice exams.
