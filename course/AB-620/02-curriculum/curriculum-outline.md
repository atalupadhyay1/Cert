# Curriculum outline — AB-620 practice course

**Microsoft AB-620: Designing and Building Integrated AI Agent Solutions in Copilot Studio**

Six mock exams × 100 original questions = 600 items. Three official domains, weighted **33 / 42 / 25** on every exam. Four case studies of three questions per exam. Mixed item types: 76 multiple-choice, 16 multi-select, and 8 sequencing items exported as multiple-choice.

## Learning arc

| Stage | What the learner does | Evidence of progress |
|---|---|---|
| 1. Diagnose | Take Exam 1 cold, untimed, no lookups | Domain split in the end-of-test report |
| 2. Study the weakest domain | Read the study-map skills behind the missed items | Can explain why each rejected option fails |
| 3. Practise scenarios | Exam 2 and Exam 3, timed at 120 minutes | Case-study blocks answered without re-reading the scenario three times |
| 4. Consolidate | Exam 4 and Exam 5, one per week | Stable scores across exams with the same weighting |
| 5. Rehearse the lifecycle | Exam 6, then the case-study briefs as a written exercise | Can describe a release process end to end |

## Exam-by-exam study plan

### Exam 1 — Planning and integration foundations (100 items)
Domain split 33 / 42 / 25. Case studies: Contoso Field Service, Meridian Claims, Fabrikam Maintenance, Northwind Commerce.
Focus: identity strategy, channels, governance, agent flows, human-in-the-loop, connector choice, computer use, MCP, multi-agent routing, evaluation basics, solution packaging.

### Exam 2 — Regulated and logistics scenarios (100 items)
Case studies: Harborview Clinics, Tailwind Logistics, Woodgrove Insurance, Alpine Retail Group.
Focus: per-user entitlement through connectors, throttled APIs, refusal discipline, Fabric data agents, reusable components across business units.

### Exam 3 — Finance, utilities, and manufacturing (100 items)
Case studies: Beacon Financial, Portside Utilities, Litware Manufacturing, Salish Education.
Focus: auditability of refusals, Azure AI Search filtering and ranking, computer use monitoring, Foundry delegation, environment variables, pipeline gates.

### Exam 4 — Support, banking, media, and public sector (100 items)
Case studies: Kestrel Support, Cobalt Bank, Trellis Media, Redwood Public Works.
Focus: approval-before-action design, custom connectors, telemetry for on-call work, ALM for regulated releases.

### Exam 5 — Healthcare, energy, banking, and utilities (100 items)
Case studies: Granite Health, Solstice Energy, Northgate Bank, Brightwater Water.
Focus: external identities, permission trimming across document estates, drafting rather than sending, detection plus diagnosis.

### Exam 6 — Cross-sector capstone (100 items)
Case studies: Lakeshore Library, Skyline Transit, Evergreen University, Atlas Distribution.
Focus: everything at once — public audiences, deployment stalls, evaluation gates, and a five-environment release path.

## Item formats and how to rehearse them

- **Single-answer (76 per exam, including 8 sequencing items).** One best answer out of four. Read the constraint first, then eliminate.
- **Multi-select (16 per exam).** Five options, two correct, stem states "Select two". Both keys are required; a partial answer scores zero in most players.
- **Sequencing (8 per exam).** Four candidate orders of the same steps. The correct one is the only order in which each step has what it needs.
- **Case studies (4 blocks of 3).** The scenario is read once; the three questions are scored individually and usually cover planning, integration, and lifecycle.

## Suggested eight-week schedule

| Week | Focus | Practice |
|---|---|---|
| 1 | Domain 1: planning, identity, channels, governance | Exam 1 cold, then review every explanation |
| 2 | Domain 1: agent flows, HITL, topics, prompts | Redo Exam 1 items you missed |
| 3 | Domain 2: connectors and knowledge routes | Exam 2 |
| 4 | Domain 2: tools — computer use, MCP, custom connectors, REST | Exam 3 |
| 5 | Domain 2: multi-agent, Foundry, Fabric, A2A | Exam 4 |
| 6 | Domain 3: test sets, evaluation, result review | Exam 5 |
| 7 | Domain 3: solutions, environment variables, pipelines, monitoring | Exam 6 |
| 8 | Weak areas and case studies | Retake one exam, write your own release plan |

## Scoring your own attempt

Score each item 1 or 0. Multi-select scores 1 only when the key set matches exactly. Sequencing scores 1 only for the correct order. Report the result by domain, not overall: a 90% average with every security item wrong is a fail in practice.

A practice percentage is not a scaled exam score. Microsoft reports 700/1000 as a scaled threshold, and no raw equivalent is published.
