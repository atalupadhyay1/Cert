## 2. Retirement & Scope Hygiene

- **Retirement Date:** Exam AZ-204 retired on **July 31, 2026** (`11:59 PM CST`), replaced by **Exam AI-200 (`Azure AI Cloud Developer Associate`)**.
- **Scaled Score Honesty:** Microsoft scored AZ-204 on a **`100–1000` scaled score** (`700` to pass), which is non-linear and does not equal `70%` raw correct answers.
- **Excluded Pre-2026 Retired Objectives:** Older community question lists often still surface pre-2024/2025 topics removed from Microsoft's January 14, 2026 study guide — specifically provisioning Azure Virtual Machines, Azure Logic Apps, Azure Notification Hubs, Azure CDN, and Azure Cache for Redis. None of those retired topics are tested as exam objectives in this 600-question bank.
