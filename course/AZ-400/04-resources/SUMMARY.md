# Build & Validation Summary — Microsoft Exam AZ-400 (`course/AZ-400/`)

## Executive Summary

- **Exam:** Microsoft Exam **AZ-400: Designing and Implementing Microsoft DevOps Solutions** (`Microsoft Certified: DevOps Engineer Expert`)
- **Official Blueprint Baseline:** **Skills measured as of July 27, 2026** (`https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/az-400`)
- **Prerequisite Disclosure:** Earning `Microsoft Certified: DevOps Engineer Expert` requires passing **AZ-400** plus holding an active **AZ-104** (`Azure Administrator Associate`) or active pre-retirement **AZ-204** (`Azure Developer Associate`) certification.
- **Lifecycle & Successor Disclosure:** Exam AZ-400 is currently live (`100 min` / `120 min` with labs, `40–60` questions, **700 / 1000** scaled passing score, `$165 USD` US). On October 15, 2026, Microsoft announced that **Exam AZ-400 and `DevOps Engineer Expert` will retire on February 1, 2027**, succeeded by **Exam AZ-401 (`Designing and Implementing Microsoft Agentic DevOps Solutions`)**.
