# PCA package summary

This course covers the **Google Cloud Professional Cloud Architect** certification.

- Six mock exams × 100 original questions = **600**.
- Every exam is blueprint-weighted **25 / 18 / 17 / 15 / 12 / 13**, the published weights (25 / 17.5 / 17.5 / 15 / 12.5 / 12.5) rounded to whole items.
- Item mix per exam: **76 single-answer, 16 multi-select**, plus **4 case studies of 5 questions**. Eight of the single-answer items are sequencing items with four candidate orders.
- Multi-select stems state the required count; sequencing items offer four candidate orders and export as `multiple-choice`, because the importer accepts only `multiple-choice` and `multi-select`.
- Six official domains, 42 local study-map skills and 24 original case-study scenarios, all mapped in the exports.
- Per-option explanations plus a case rationale, exam-guide anchor, local skill, and primary reference on every item.
- Exam baseline: **2 hours**, **$200 USD** plus tax, **50–60 questions**, **2 case studies worth 20–30%** — all Google-published on the certification page. The **passing score is not published**, so no target percentage is stated anywhere.
- Each practice exam is 100 items, so the blueprint is drilled twice. It is an expanded bank: the live exam samples 50–60 questions.
- Configuration is deliberately in scope: items show IAM conditions, organization policy constraints, organization and folder bindings, subnet and routing choices, lifecycle and retention settings, checkpoint and watermark patterns, Terraform delivery, and release mechanics, and test the judgement behind the change rather than command recall.
- Official case studies are **named but never reproduced**. All 24 scenarios in the bank are invented companies.
- Not reproduced: the split-screen case-study panel, drag-and-drop ordering, lab tasks, and interactive console components.
- Offline ZIP: `Google-Professional-Cloud-Architect-6x100.zip`.

Automated checks cover structure, blueprint allocation, item-type mix, source parity, explanation pairing, CSV bytes, cross-exam duplicate wording, case-scenario coverage, and archive reproducibility. They do not establish independent technical accuracy, psychometric quality, platform import success, or a passing result.

Google does not publish a passing score, so no practice percentage converts to a pass mark.
