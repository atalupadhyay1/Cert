## 1. Course Structure on Udemy (Practice-Test-Only Course)

Udemy practice-test courses contain six standalone Practice Test curriculum items (no video lectures required):

| Section / Item | Title | Questions | Recommended Timer | Pass Target (Udemy) |
|---|---|---:|---:|---:|
| Practice Test 1 | Full-Length Mock Exam 1 — Retail Store Operations | 100 | 75 min (`45 min` speed drill) | 75% |
| Practice Test 2 | Full-Length Mock Exam 2 — Healthcare Clinic Onboarding | 100 | 75 min (`45 min` speed drill) | 75% |
| Practice Test 3 | Full-Length Mock Exam 3 — Municipal Citizen Services | 100 | 75 min (`45 min` speed drill) | 75% |
| Practice Test 4 | Full-Length Mock Exam 4 — Manufacturing Field Quality | 100 | 75 min (`45 min` speed drill) | 75% |
| Practice Test 5 | Full-Length Mock Exam 5 — Financial Client Services | 100 | 75 min (`45 min` speed drill) | 75% |
| Practice Test 6 | Full-Length Mock Exam 6 — Global Logistics & Campus HR | 100 | 75 min (`45 min` speed drill) | 75% |
| **Course Total** | **6 Full-Length Blueprint-Weighted Mock Exams** | **600** | **450 min total** | **75% benchmark** |

### Why 75 Minutes (and Optional 45-Minute Speed Drill)?

- **Live Exam PL-900:** `45 minutes` exam time (`65 minutes` total seat duration) for `40–60` standalone questions -> **`45 to 67.5 seconds per question`**, **closed-book** (no Microsoft Learn access), **zero case studies**, and **zero live labs**.
- **100-Question Expanded Practice Set:** Setting Udemy's timer to **`75 minutes`** gives **`45 seconds per question`**, matching the upper-speed pacing of a 60-question live paper while testing all 34 official skills in every single sitting. For final-week recall stamina, candidates can re-run sets at **`45 minutes`** (`27 seconds per question`).

| Blueprint Change (Effective July 24, 2026) | Impact on Candidates |
|---|---|
| **Standalone Power Pages domain (`15–20%`) removed** | You no longer need deep Power Pages studio/Liquid/table-permission design; Power Pages is tested for its **business value** in building external websites (`Skill 1.3`). |

## 3. Complete 34-Skill Study Map (`100` Questions/Exam · `600` Total)

### Domain 1 — Describe the business value of Microsoft Power Platform (`5–10%` -> `8` / exam · `48` total)

- **`1.1`** Describe the business value of Microsoft Power Apps and Microsoft Power Automate (`2/exam · 12 total`)
- **`1.2`** Describe the business value of Microsoft Dataverse and connectors (including on-premises data gateway) (`2/exam · 12 total`)
- **`1.3`** Describe the business value of Microsoft Power Pages to build external websites (`2/exam · 12 total`)
- **`1.4`** Describe the business value of generative AI features in Power Platform and Copilot Studio to create agents (`2/exam · 12 total`)

### Domain 2 — Manage the Microsoft Power Platform environment (`20–25%` -> `23` / exam · `138` total)

- **`2.1`** Describe differences between traditional databases and Microsoft Dataverse (`2/exam · 12 total`)
- **`2.2`** Describe Dataverse tables (`Standard`, `Custom`, `Virtual`, `Elastic`), columns, `Choices`, and `1:N` / `N:N` relationships (`3/exam · 18 total`)
- **`2.3`** Describe Dataverse table forms (`Main`, `Quick Create`, `Quick View`, `Card`) and views (`Public`, `System`, `Personal`) (`2/exam · 12 total`)
- **`2.4`** Describe options for business logic in Dataverse (`Business Rules`, `Power Fx` formula columns, `Rollup` columns) (`3/exam · 18 total`)
- **`2.5`** Describe how to use AI (`Copilot`) to create and edit Dataverse tables, columns, and relationships (`2/exam · 12 total`)
- **`2.6`** Describe Power Platform environments (`Default`, `Developer`, `Sandbox`, `Production`, `Trial`) and `Managed Environments` (`2/exam · 12 total`)
- **`2.7`** Describe the Power Platform security model (`Entra ID`, `Business Units`, `Security Roles`, `Teams`, `Column Security`) and `DLP` policies (`3/exam · 18 total`)
- **`2.8`** Describe how Microsoft Power Platform supports data privacy (`Purview` / `GDPR`) and accessibility guidelines (`Accessibility Checker`, `AccessibleLabel`, `TabIndex`) (`2/exam · 12 total`)
- **`2.9`** Describe monitoring and analytics capabilities (`Power Platform Admin Center`, capacity, `Monitor`, `Advisor`) (`2/exam · 12 total`)
- **`2.10`** Describe ALM with `Solutions` (`Unmanaged` vs `Managed`, `Environment Variables`, `Connection References`) and `Power Platform pipelines` (`2/exam · 12 total`)

### Domain 3 — Demonstrate the capabilities of Power Apps (`20–25%` -> `23` / exam · `138` total)

- **`3.1`** Describe use cases for and capabilities of canvas apps (connectors, galleries, forms, basic `Power Fx`) (`4/exam · 24 total`)
- **`3.2`** Describe use cases for and capabilities of model-driven apps (Dataverse requirement, forms, views, `Business Process Flows`) (`4/exam · 24 total`)
- **`3.3`** Describe use cases for and capabilities of `Plan designer` (`3/exam · 18 total`)
- **`3.4`** Describe use cases for and capabilities of `Power Apps code apps` (`3/exam · 18 total`)
- **`3.5`** Describe how to use AI (`Copilot`) to create and edit a canvas app (`3/exam · 18 total`)
- **`3.6`** Describe how to use AI (`Copilot`) to create and use a model-driven app (form fill, view filter, chat) (`3/exam · 18 total`)
- **`3.7`** Describe creating AI-powered apps by using the `Power Apps vibe` experience (`Plan.md`, draft tables, `Publish draft tables`) (`3/exam · 18 total`)

### Domain 4 — Demonstrate the capabilities of Power Automate (`20–25%` -> `23` / exam · `138` total)

- **`4.1`** Describe use cases for cloud flows (`Automated`, `Instant`, `Scheduled`) and desktop flows (`Attended` / `Unattended` RPA, `Process Mining`) (`5/exam · 30 total`)
- **`4.2`** Describe Power Automate use cases for `Approvals`, `Teams`, `Outlook`, `SharePoint`, `Forms`, and `AI Builder Document Processing` (`5/exam · 30 total`)
- **`4.3`** Describe connector triggers, actions, `Dynamic Content`, `Condition` branches, `Apply to each` loops, and `Run History` (`5/exam · 30 total`)
- **`4.4`** Describe how to use AI (`Copilot` & `AI Prompts`) to create, explain, and modify cloud flows (`4/exam · 24 total`)
- **`4.5`** Describe how to use AI (`Copilot`) and `Recorder` capabilities to create and modify desktop flows (`4/exam · 24 total`)

### Domain 5 — Describe features and capabilities of agents in Microsoft Copilot Studio (`20–25%` -> `23` / exam · `138` total)

- **`5.1`** Describe use cases for conversational and autonomous agents (standalone and extending `Microsoft 365 Copilot`) (`3/exam · 18 total`)
- **`5.2`** Describe how to build agent conversation paths by using `Topics` (`Message`, `Question`, entities/variables, `Condition`, system topics) (`3/exam · 18 total`)
- **`5.3`** Describe how to use `Knowledge sources` in agents (permission grounding across `SharePoint`, `OneDrive`, `Dataverse`, files, public URLs) (`3/exam · 18 total`)
- **`5.4`** Describe how `Tools`, including `Model Context Protocol (MCP)` servers and `agent flows`, are used in agents (`3/exam · 18 total`)
- **`5.5`** Describe how to `Publish` agents by using `Channels` (`Teams`, `M365 Copilot`, websites, `SharePoint`) and authentication (`3/exam · 18 total`)
- **`5.6`** Describe use cases and capabilities for `Microsoft Agent 365` (Entra agent identities, Conditional Access, inventory, Defender) (`3/exam · 18 total`)
- **`5.7`** Describe how to monitor Copilot Studio agent usage and adoption (`Resolved` / `Escalated` / `Abandoned`, `CSAT`, Copilot credits) (`2/exam · 12 total`)
- **`5.8`** Describe `Agent Evaluations` in Microsoft Copilot Studio (test sets, graders, content safety, `Activity map`, `Compare with`, `Agent viewer` role) (`3/exam · 18 total`)
