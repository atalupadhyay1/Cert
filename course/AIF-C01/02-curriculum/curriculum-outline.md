Every test mixes all five domains in the same 20/24/28/14/14 proportions. These are balanced practice sets, not six domain-specific sections or progressively calibrated difficulty levels. Core concepts repeat deliberately; later tests are not independent estimates of readiness.

## Practice instructions

Select one answer unless instructed to select two. For a select-two question, award credit only when both correct options and no other options are selected. Use 80% as a suggested practice target, not an AWS scaled score. Review low-confidence correct answers as carefully as wrong ones.

**140 minutes is a custom setting for these 100-question practice tests.** Consult the official certification page for current real-exam duration and delivery details. The AWS guide describes 50 scored and 15 unscored questions, with a minimum scaled score of 700 on a 100–1,000 scale. Do not convert that scaled threshold directly into a raw practice percentage.

The current guide lists multiple choice, multiple response, ordering, and matching. This CSV package uses single-answer and multiple-select questions, not native interactive ordering or matching tasks.

## Suggested three-week study plan

### Week 1 — Establish a baseline

1. Read the official content outline and complete Test 1 without notes.
2. Record weak domains and mark guesses even when correct.
3. Review learning paradigms, lifecycle, task types, data quality, and AWS AI service selection.
4. Complete Test 2 and compare your reasoning rather than just the score.

### Week 2 — Apply and diagnose

1. Study RAG, prompting, model adaptation, evaluation, cost, and latency tradeoffs.
2. Complete Test 3 and write a short explanation for each missed concept.
3. Review fairness, explainability, human oversight, access controls, encryption, and governance.
4. Complete Test 4 and consult linked documentation for uncertain distinctions.

### Week 3 — Consolidate

1. Complete Test 5 under the suggested practice conditions.
2. Review agents, tools, source provenance, model evaluation, and security responsibilities.
3. Complete Test 6 and explain why alternative answers are inappropriate.
4. Revisit weak objectives using fresh examples rather than memorized answer letters.
5. Check the current exam guide for examples and formats not reproduced by these tests.
