# Udemy Bulk-Upload CSV Format Specification (`PL-600`)

All CSV files generated by `04-resources/build.py` (`practice-set-{1..6}.csv`, `case-embedded-set-{1..6}.csv`, and `05-sample-upload/case-study-sample.csv`) conform strictly to Udemy's 17-column practice-test import schema (`UTF-8` without BOM, `\n` LF line endings, RFC 4180 `QUOTE_MINIMAL`).

## Column Schema (`17` Columns)

| Col # | Exact Header | Rules Enforced by `build.py` & `validate.py` |
| :---: | :--- | :--- |
| `1` | `Question` | Non-empty plain/markdown-safe text (`<= 520` chars standalone; `<= 799` chars in `case-embedded-set-*.csv`, well under Udemy's `1,000`-char ceiling). Multi-select stems explicitly state `Select two.` or `Select three.` |
| `2` | `Question Type` | Strictly `multiple-choice` (`84` / set: `76` `S` + `8` `O`) or `multi-select` (`16` / set: `13` `M2` + `3` `M3`) |
| `3–4` | `Answer Option 1`, `Explanation 1` | Non-empty (`<= 255` char option, `<= 550` char rationale prefixed `Correct.` or `Incorrect.`) |
| `5–6` | `Answer Option 2`, `Explanation 2` | Non-empty |
| `7–8` | `Answer Option 3`, `Explanation 3` | Non-empty |
| `9–10` | `Answer Option 4`, `Explanation 4` | Non-empty |
| `11–12` | `Answer Option 5`, `Explanation 5` | Populated for 5- or 6-option `M2`/`M3` items; empty `""` for 4-option `S`/`O` items |
| `13–14` | `Answer Option 6`, `Explanation 6` | Populated for 6-option `M2`/`M3` items; empty `""` otherwise (options are strictly contiguous from `1..N`) |
| `15` | `Correct Answers` | 1-based comma-separated integer indices (`e.g. 2` for `multiple-choice`, `1,4` or `2,5,6` for `multi-select`), deterministically seeded per `PL-600:<QuestionID>` |
| `16` | `Overall Explanation` | Synthesizes architectural reasoning + `[Skill X.Y: <Skill Title> | Source: <Title> (<https://learn.microsoft.com/...>)]` (`<= 1,150` chars) |
| `17` | `Domain` | Exact official September 23, 2024 functional group name (`Perform solution envisioning and requirement analysis`, `Architect a solution`, or `Implement the solution`) |

## Microsoft Interactive Item-Pattern Approximations

Because Udemy CSV uploads support `multiple-choice` and `multi-select` only, `PL-600` adapts live Microsoft exam patterns transparently:
- **API / Schema / Governance Completions (`____`):** `173` items across the 6 sets (`22–33` / set).
- **`Proposed solution:` Yes/No Evaluations:** `37` items across the 6 sets (`6–7` / set) embedded inside self-contained stems (avoiding Udemy's unsupported non-returnable lock screen).
- **Ordered 4-Step Sequences (`→`):** `48` items across the 6 sets (`8` / set) testing chronological Solution Architect workflows.
- **Multi-Question Case Studies:** `24` original 3-question case studies (`4` / set = `72` items) shipped in both compact (`practice-set-*.csv`) and inline randomization-safe (`case-embedded-set-*.csv`) editions.
